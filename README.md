# 视频上传填表助手

面向 Chrome / Edge 的本机浏览器扩展：一次选择一个视频，逐个平台上传和填表，最终交给用户检查与手动发布。

**当前为小红书、快手、抖音、视频号和 B 站填表实验版，完整第一版尚未完成。** 已有平台的扩展上传、文案与封面验证以 `docs/verification/browser-handoff.md` 的证据为准。

## 构建与安装

需要 Node.js 24+。

```sh
npm ci
npm run build
```

在 Chrome 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，选择此仓库的 **dist** 目录。Edge 对应 `edge://extensions`；Edge 尚待实测。

点击扩展图标打开工作台。选择本地视频、勾选目标平台，点击“开始文件交接验证”，按提示授予所选平台访问权限。运行时保持工作台打开。

## 从 ShotBase 导入

使用 Chrome 148 或更新版本。默认构建接收来自 `http://localhost` 和 `http://127.0.0.1` 的页面请求。若通过局域网地址打开 ShotBase，构建时加入该地址，然后在 `chrome://extensions` 重新加载插件。

```sh
VIDEO_UPLOAD_IMPORT_ORIGINS=http://192.168.2.4:5001 npm run build
```

`VIDEO_UPLOAD_IMPORT_ORIGINS` 接受逗号分隔的 HTTP/HTTPS 来源，Chrome 按协议和主机匹配网页。在 ShotBase「一键发布」里的「插件连接设置」填写一次插件 ID，浏览器会自动记住。

网页可用 `chrome.runtime.sendMessage(extensionId, message)` 发送 `video-upload.import.v1`。字段包括 `type`、32 位小写十六进制 `requestId`、`video` 文件、`title`，以及可选的 `candidateTitles`、`tags` 字符串数组和 `collection` 合集名称。封面可使用单个 `cover` 文件，或按主封面、PK 候选顺序传入 `covers` 文件数组。收到 `{ok: true, imported: true}` 表示工作台已保存素材。可先用 `video-upload.import-check.v1` 和相同的 `requestId` 检查是否可导入。空工作台返回 `supportsAllCovers: true` 时可以传入全部封面，`maxCovers` 用于兼容旧发送端。同时返回 `supportsTags` 和 `supportsCollection`。同一来源与请求 ID 可安全重试，其他新批次需等工作台清空。

工作台打开后，可以调整封面顺序，修改标题、标签和合集名称，再选择平台并开始。小红书使用前 4 张封面。「合集名称」用于匹配小红书、抖音和视频号已有的合集，留空时跳过。

## 小红书自动填写

选择视频后，可填写标题、内容描述、标签并选择封面，然后只勾选小红书。封面 PK 默认开启，可手动关闭；一次最多选择 4 张图片，第一张作为主封面，其余依次作为最多 3 张 PK 候选。多图需开启 PK；可逐张移除候选。首次任务启动后，本批次文案和封面锁定。标题最多 20 字符、正文连标签最多 1000 字符、最多 10 个标签；超限报错，不静默截断。单图支持 JPG/PNG/WebP，多图支持 JPG/PNG，每张最大 20 MiB，封面只支持 4:3 或 3:4 比例。

插件等待页面显示视频上传完成后填写并回读文案。除 B 站使用平台标签控件外，其它支持标签的平台按 `#标签` 附加在正文后，**不会自动选择平台话题候选**。自定义封面仅在识别到专用裁剪面板、新图原始字节匹配及稳定预览变化时确认；仅 canvas 或平台重新编码后的预览无法核验时，也会停在页面交由你处理。请检查裁剪效果，不选封面则保留默认封面。PK 会使用平台推荐候选；选择自定义候选时逐张编辑系统推荐图，遇到已有自定义候选会停止，不覆盖。平台可能记忆 PK 开关设置。完成后仍为“需你处理”，不发布、不点存草稿。

填写“定时发布时间”后，插件会在各平台存在的定时控件上开启定时发布并回读本机时间；只能选择未来 7 天内的时间，也可以在开始前点击“清理定时”移除设置。没有对应控件的平台会跳过该项。设置只作用于编辑页，仍需你检查后点击平台自己的发布按钮。

已完成真实小红书扩展端四图填表和快手双图填表验证，具体证据与限制见 `docs/verification/browser-handoff.md`。已有扩展只需重新加载当前 `dist`，无需重新安装。

## 抖音自动填写

入口使用抖音上传页。插件交接一次视频后，仅接续由该上传页打开的确切编辑页；不会在新tab重复上传。填写独立标题（最多30字）、正文与标签（合计1000字），按4:3/3:4各取第一张作为横/竖封面。工作台的“合集名称”有值时，发布页会打开“请选择合集”，只选择名称完全相同且唯一的已有合集，并回读确认；填写定时发布时间时也会设置并回读定时控件。找不到合集或控件有歧义就停下让你检查。抖音不使用PK开关。保持编辑页前台，最后人工检查，不发布、不点暂存离开。

已完成 Chrome 扩展真站整条流程：视频上传、标题/正文/标签回读和横竖双封面应用。素材与文字保留在编辑页供人工检查；接续记录及截图见 `docs/verification/browser-handoff.md`。

## 快手自动填写

作品描述仅填写标题，换行后附加前 4 个 `#标签`，不使用正文。超出 4 个的标签自动忽略，不阻止开始，也不修改小红书的共享文案。

封面只支持 4:3、3:4；快手提供主封面和 1 张 PK 封面。两种比例都有时随机各选一张（4:3 主封面，3:4 PK）；只有一种比例时随机选两张不重复图片，只有一张时用一张。PK 关闭时仅使用主封面。选中素材 ID 保存在任务里，重试沿用，不重新抽选。

需要保持快手标签页在前台。先回读作品描述，再核验封面裁剪器原图像素，限定在封面弹窗内点击确认，并检查预览实际更新。最后停在编辑页，不发布、不点存草稿；标签仍为文本，需要人工检查话题与裁剪。页面已有文案会停止保护，快手自身可能恢复上次未发布内容。

## 文件交接怎样工作

- 视频只在扩展的 IndexedDB 中保存一份；元数据在 `chrome.storage.local`，不会上传到插件服务器。
- 依次打开所选平台的新编辑页，保守检查页面是否已有内容、是否存在唯一视频文件入口。
- 用扩展桥接页和一次性授权交接 Blob，不把视频编码进普通消息通道。
- 未配置小红书文案或封面时，文件交给控件后显示“需你处理”。**这不表示平台接受或完成了上传**；请打开页面观察上传进度、处理结果和预览。
- 各平台在填写和核验完成后停在编辑页。支持的平台会填写并核验创作声明，不清除原稿，不操作投稿或发布。
- 可信输入、平台导航、工作台关闭、连接断开或“停止并接管页面”会终止后续操作。平台已收到的上传可能继续。
- 同一批次不会自动重复上传。平台标签页已关闭时，可在最新平台记录点击“保留素材重新打开”，沿用视频、文案和全部封面重新上传填写，并保留旧尝试记录；原页面仍打开时拒绝重试。重新打开工作台本身只恢复记录。
- “结束并清理素材与记录”只删除插件缓存，不关闭或删除平台页面。闲置素材超过 24 小时会在下次打开时清理；运行中批次保留。缓存被浏览器回收时需重新选文件。

遇到登录页面、已有原稿、多个入口、iframe/CSP 限制或控件不接受时会停止，保留页面供人工检查。使用 storage、scripting、webNavigation 权限；webNavigation 用于区分实际导航和重复加载通知，代码只处理当前任务标签页的主页面事件，不保存浏览历史。不需要 cookies、debugger、nativeMessaging、tabs 或 unlimitedStorage 权限。

## 开发验证

```sh
npm test
npm run typecheck
npx playwright install chromium
npm run check
```

`test:browser` 在临时 Chromium Profile 中加载真实打包扩展，将五个目标域名解析到**本机 HTTPS 测试夹具**，其他域名不可解析，不访问账号、不上传到真实平台。测试 Profile 仅对本机自签名测试证书放宽证书检查。测试副本预授予相同的五个 host permission 以避开自动化权限弹窗，生产 `dist` 保持按需申请。

测试覆盖跨源字节一致性、不投稿、所有平台均不自动保存草稿、旧版 B 站草稿记录只读核验、重复启动保护、原稿保护、人工编辑接管、导航与工作台断开以及缓存清理。输出位于忽略的 `artifacts/`，不是五站验收报告。实际平台权限弹窗、控件兼容、上传完成以及浏览器最低版本/容量范围须另行实测。

## 诊断日志

诊断版 2026-11-09.2 自动将工作台点击、前置拦截、权限请求/结果、后台请求关联 ID、连接变化及任务状态保存在 `chrome.storage.local` 的 `diagnostics.workbench` 和 `diagnostics.background`。各保留最近 300 条，刷新或关闭页面后仍保留；清理素材不会删除诊断日志。日志写入失败不阻断上传。

点击开始按钮附近的“导出诊断日志”可下载 `video-upload-diagnostics.json`。不记录标题、正文、标签、文件名/路径/内容、账号或桥接授权令牌；错误以分类标识记录。日志仅保存在本机浏览器，不自动传往服务器。工具无法访问扩展内部时仍需导出文件，不能自动读取受限浏览器数据。

### 下载/保存权限

快手自动取消“允许下载此作品”；抖音自动选择保存权限“不允许”，并回读核验。仅交接视频、未填写文案时也检查此设置。权限控件缺失、歧义或状态回滚时提示人工检查，不会标记为成功。

小红书跳过下载/保存权限检查。小红书、快手和抖音仍停在编辑页，不发布、不保存草稿。

### 视频号

视频号使用创作者页面内的编辑 iframe，自动交接视频后填写“短标题”和“视频描述”，并回读核验字段。检测到已有文案会停止保护原稿，流程停在编辑页，不发表、不保存草稿。

### B 站

B 站自动交接视频后填写稿件标题、简介、平台标签和单张 JPG/PNG 封面，选择“亲子”分区，并分别回读核验。标签通过平台“按回车键 Enter 创建标签”控件生成在标签行，不写入简介；仅跳过平台明确拒绝的单个标签，继续添加其余标签，并在结果中列出跳过项。网络异常或校验结果不明时停止，不把它当作标签拒绝。检测到已有不同文案会停止保护原稿。上传和填写完成后保留当前编辑页，请在原标签页确认后点击“立即投稿”。插件不会点击“存草稿”或“立即投稿”。B 站上传页需要保持在前台，平台话题和其它投稿设置仍需人工检查。

旧版验证时，真实扩展曾保存并重开草稿 `4129814`，标题、视频、封面及 AI 声明保留，见 [页面草稿改造与验证](docs/verification/2026-11-16-bilibili-page-draft-implementation.md)。后续已在同一草稿验证只跳过“幼儿英语启蒙”，其余五个标签及亲子分区保存成功，见 [标签与亲子分区验证](docs/verification/2026-11-17-bilibili-tags-category.md)。
