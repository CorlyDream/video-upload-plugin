# B 站标签逐项跳过与亲子分区（2026-11-17）

用户要求：只跳过平台拒绝的单个标签，继续添加剩余标签；视频分类选“亲子”。仅保存草稿，不投稿。

## 实现

- 添加标签前执行官方 TagInput 使用的两个 GET 校验：`/x/app/h5/archive/tag/info?tag_name=...` 与 `/x/vupre/web/topic/tag/check?tag=...`。
- 仅在 HTTP/外层 code 成功、内层明确拒绝且有原因时，记录该标签并继续。登录失败、网络失败、缺失/未知校验结果均停止，不作为拒绝标签跳过。原配置标签数组保留。
- 通过页面标签输入框和 Enter 添加允许的标签，逐项核对页面标签。跳过清单随任务检查点及保存意图持久化，最终说明列出跳过项。
- 页面选中“亲子”，保存前核对页面模型 `archive.tid=193`，保存后核对草稿 `tid=193`。
- 保存后仍要求所有未被拒绝的配置标签存在；不能用某一项被拒绝来豁免其它标签丢失。
