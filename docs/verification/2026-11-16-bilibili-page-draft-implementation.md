# B 站页面草稿改造与验证（2026-11-16）

## 实现边界

- 移除 B 站直传并调用投稿接口的分支。当前流程为缓存 Blob → 页面上传卡片 → 上传完成 → 填写/核验 → 页面“存草稿” → list/view 只读核验。
- 不点击“立即投稿”，不回退到投稿接口。仅支持能够核验身份的单视频任务；已有投稿的 edit/aid/bvid 页面拒绝作为草稿处理。
- 等待 `.bcc-upload-wrapper`，不把微应用尚未加载时唯一的底层 `buploader` 当作可用入口。通过 B 站微应用代理窗口获取上传配置和页面模型。
- 上传配置未就绪时返回等待状态，由可取消的内容脚本轮询；停止后不留延迟触发上传的 MAIN-world 回调。
- 保存前核对真实页面模型中的视频 cid/filename、标题和简介。先持久化保存意图，再点击一次“存草稿”。结果不明或断连后仅查询，禁止重复保存或重新上传。
- B 站进度根据已核验步骤记录，不再把前面的步骤根据当前位置推断为完成。旧版“稿件草稿”记录迁移为投稿接口历史记录提示；旧记录不能继续当作草稿任务。
- 继续同步复用已上传视频，并跳过已确认完成的封面。已保存的任务提供“打开草稿”；不自动再次更新已保存草稿。
